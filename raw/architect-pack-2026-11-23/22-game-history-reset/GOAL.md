# Meridian game history reset

Goal ID: goal_933f57f2e639
Goal slug: meridian-game-history-reset

## Description
Add a 'Reset my history' control in the Review screen that lets the player delete past misses and game history and start over, with a two-step confirmation naming exactly what gets deleted. The reset clears the misses deck, learning records, seen-history, and any paused run that could re-seed them, while keeping badges, settings, and the age profile. Also fix the REVIEW button overlay on the card artwork, with a phone-width overlap test as proof.
