# Holmes and Watson detective pair build

Goal ID: goal_ca1e9af9850a
Goal slug: holmes-and-watson-detective-pair-build

## Description
Build the Holmes and Watson voice companion for Meridian's detective games, starting with the 110 Capitals cases and adding the 387 core cases after gates. Watson reads each clue aloud and Holmes decodes it, searches the hovered area, and celebrates or commiserates at the solve. Audio is pre-rendered, the pair ships behind the detectivePair flag, and the build runs as units U1–U10 through a PR and a flag-ON video for Veeresh's eye.
