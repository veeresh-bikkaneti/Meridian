## ww2-monuments:arizona-how-far (group 10-18)

Clip:

Hey kids, have you heard about this place?
This Hawaii memorial is one hundred eighty-four feet long.
How many ten-foot steps is that?

Host explain, after the answer:

Eighteen tens make one hundred eighty. Four feet are left over.
The pin is Pearl Harbor, in Hawaii.

Hint on a miss:

Make groups of ten. Count the groups. Count what is left.

7-10 card if a younger player meets this clip (same movie):

Is one hundred eighty-four feet longer than one hundred feet?

18+ extra card, same clip. Group size eight is a problem unit, not a site fact:

Now use groups of eight feet. How many groups fit in one hundred eighty-four,
and what is left?
