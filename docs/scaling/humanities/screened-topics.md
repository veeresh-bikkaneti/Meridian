## How to read the columns

- **Group**: by school grade of the cited standard. 7-10 = grades 2-5, 10-18 = grades 5-12, 18+ = adults beyond grade 12. Grade 5 may go in either. No algebra or trigonometry in 7-10.
- **C3 family**: the C3 Framework dimension and grade band the topic would be coded under. **Every indicator number is UNVERIFIED** (see "Sources" below); the family is a pointer for the educator, not a citation. `D2.His` = History, `D2.Geo` = Geography, `D2.Civ` = Civics, `D2.Eco` = Economics.
- **Objective**: written the §2 way, with an observable verb and what the game sees. Counts of items per topic are not set (TO CONFIRM).
