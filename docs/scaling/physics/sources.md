# Physics item sources

Fetched 2026-11-10. Curriculum named for physical-science items: Next
Generation Science Standards, physical science only (standard §2). Rate and
trigonometry items cite Common Core State Standards for Mathematics, because
that is the skill the round asks the player to show. No life-science code is
used.

Confidence HIGH means the opening line below was returned by a live fetch or
search extract of that page on this date. Fit of an item to its code is for
the educator (rubric A3), not claimed here. A code with no row is not used.

Play numbers (8 tiles, 2 tiles, 4 pushes, 3 tiles, 1 tile, rises 2 and 4,
8 metres in 2 seconds, 9 metres in 3 seconds, 12 kilometres, 4 kilometres
per hour, 5 units, 2 units) are problem givens. None is a measured fact
about a real place, product, or device.

Direct requests to some performance-expectation pages returned HTTP 202 with
an empty body. Where that happened, the sentence is taken from the standards
search extract or the evidence-statement PDF on the same site, and the URL
in the table is the page that extract names.

## Cut or not taught

- **Pulley mechanical advantage, and a pulley changing the direction of a pull.** No physical-science performance expectation found on 2026-11-10 states either effect. Core Knowledge's grade-1 simple-machines note says NGSS does not prescribe a simple-machines performance expectation (their document, not an NGSS page). The family stays in the data as a closed round.
- **Wheel and axle making work easier, or reducing friction.** Same gap. Closed round.
- **A longer lever needs a smaller push.** Not in 3-PS2-2. The see-saw round only uses the pattern the clarification names.
- **A steeper ramp ends faster than a gentler ramp that starts at the same height.** Not taught. Same-height ramps are a known trap; final speed is not claimed.
- **A heavier object falls faster, or two objects fall in the same time.** 5-PS2-1 states direction only. Its boundary excludes a mathematical representation.
- **Rough always means a shorter slide.** Not stated on 3-PS2-1 or 3-PS2-2. The friction round repeats one measurement.
- **More winds send the toy farther.** Not stated on 4-PS3-4.
- **Named magnetic poles, and "opposites attract" as a slogan.** 3-PS2-3 says orientation changes direction. MS-PS2-3 says the forces can be attractive or repulsive. Pole letters are not on those lines, so they are not used.
- **Angle in equals angle out.** Not on 1-PS4-3 or MS-PS4-2. Not taught.
- **Any safe ladder angle, real tower height, glacier speed, or speed of sound or light.** Not stated. The map names some of those settings; the quantities would be unverified, so they are left out.
- **Trigonometry inside an MS-PS2-2 round.** That code's assessment boundary says assessment does not include trigonometry. The ramp-ratio rounds cite HSG.SRT.C.8 instead.
- **Ohm's law.** It appears only as the example on the HSA.CED.A.4 page. It is not an item.
- **Biology, including plants in a light-and-shadow story.** Owner rule. The lamp story uses a wall, not a living thing.
