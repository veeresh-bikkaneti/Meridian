## The known giveaway case (decision)

`chemistry:mixtures:dissolve`: its lead says the dissolved solid is
still in the water, which is its answer (token "still").
`scripts/lint-subject-leads-baseline.json` baselines exactly that leak
(GIVEAWAY, match "still"), so lint:subjects passes it as KNOWN. A
strict validator would throw on it and disagree with lint:subjects.
Decision: the validator carries a `KNOWN_GIVEAWAY_CASES` list with
that single {id, token} pair; when the leaked token matches, it
prints a known-case line naming the id, the token and the baseline
file, and continues. Any other leak still throws. Content does not
change in this PR — fixing the lead is a content change for a later,
educator-reviewed PR. A scratch check before wiring confirmed the
plain leads leak only this one record, with exactly token "still".
